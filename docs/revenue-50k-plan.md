# 月5万円収益化プラン

**ゴール:** 90日以内に月5万円の収益を安定させる。
**前提の正直な整理:** 収益はツールや計画だけでは発生せず、営業・納品というあなたの行動が必要。本プランは「行動あたりの成功確率が最も高いルート」に張る。収益保証ではない。

---

## 1. ルート比較（なぜ受託か）

| ルート | 月5万到達の目安 | 初収益まで | 再現性 | 判定 |
| --- | --- | --- | --- | --- |
| **Web制作・LP制作の受託（AI活用）** | 1件3〜5万円 × 月1〜2件 | 2週間〜1ヶ月 | 高（需要が常時ある） | **採用（主軸）** |
| アプリ販売（WakeUpQR） | 月2,800DL×転換3%×¥600 が必要 | 3ヶ月〜（開発完了後） | 低（ヒット依存） | 継続するが中長期の柱 |
| コンテンツ販売（note・Kindle・テンプレ） | 単価500〜3,000円×月20〜100本 | 1〜3ヶ月 | 中（集客力依存） | 受託の実績記事として副次的に |
| 広告収入（ブログ・YouTube） | 月数万PV〜数万再生 | 6ヶ月〜 | 低 | 不採用 |

**受託を選ぶ理由:** 月5万円は「誰かの困りごとを1〜2件解決する」だけで届く金額。集客ゼロからでもクラウドソーシングに既存の発注者がいるため、確率が営業量に比例する（運に比例しない）。そしてこの事業はAI（Claude）に制作を任せられるため、あなたの役割は**受注・要件ヒアリング・納品確認**に絞れる。

## 2. 商品設計

| プラン | 内容 | 価格 | 納期 |
| --- | --- | --- | --- |
| LPプラン | 1ページ（スマホ対応・お問い合わせ導線・公開作業込み） | ¥30,000 | 3営業日 |
| ホームページプラン | 最大5ページ（トップ・サービス・料金・会社概要・問い合わせ） | ¥50,000 | 7営業日 |
| 更新・保守 | 月2回までの文言/画像差し替え・軽微修正 | ¥3,000/月 | — |

- **月5万円の組み立て例:** LP×2件、またはHP×1件、または「LP×1＋保守×7契約」。
- 保守契約はストック収益。**10契約で月3万円が固定化**し、受託の波を吸収する。全案件で必ず提案する。
- 初回2〜3件は「実績・レビュー獲得価格」として¥10,000で受け、レビューが付いたら定価に戻す。

### 制作フロー（あなた×AIの分業）

```
受注 → ヒアリング（テンプレ質問票を送るだけ） → 回答をClaudeに渡して制作指示
→ 生成されたページを確認 → 修正指示 → 納品（GitHub Pages/Netlify等で公開）
```

1件あたりのあなたの実働目安: 2〜4時間。時給換算7,000円以上。

## 3. 販売チャネル

1. **クラウドワークス／ランサーズ（提案型）:** 「LP制作」「ホームページ制作」案件に毎日3件提案する。提案文テンプレは [service-listings.md](./service-listings.md)。
2. **ココナラ（出品型）:** 出品して待つ＋アクセス数を見て文言改善。手数料22%を織り込む（¥30,000売上→手取り約¥23,400）。ココナラ経由は定価を¥35,000に設定して調整。
3. **自前の営業サイト（`services/index.html`）:** 手数料ゼロの直接受注窓口。ポートフォリオを兼ねる。SNSプロフィール・提案文の署名からリンクする。

## 4. 90日ロードマップ

| 期間 | やること | 達成基準 |
| --- | --- | --- |
| **Week 1** | 開業届提出／営業サイト公開／ココナラ・クラウドワークス登録・出品／ポートフォリオ3点掲載 | 出品が公開状態になる |
| **Week 2〜4** | クラウドワークスで毎日3件提案（計60件超）。初回は¥10,000で受注しレビュー獲得 | 初受注1件・レビュー1件 |
| **Month 2** | 実績3件到達→定価（¥30,000〜）へ。全納品時に保守（¥3,000/月）を提案 | 月商3万円・保守1〜2契約 |
| **Month 3** | 提案文・出品文を実績数値で更新。月2件ペース＋保守の積み上げ | **月商5万円** |
| 並行 | WakeUpQR開発を週数時間で継続（中長期の柱・ポートフォリオ実績としても機能） | Phase 2完了 |

**撤退・修正基準:** 60件提案して受注ゼロなら、提案文・価格・ターゲット（業種特化: 美容室/整体/飲食など）を変更して再試行。「やめる」のではなく「変数を変える」。

## 5. ポートフォリオ（現時点で3点確保済み）

1. **WakeUpQR LP**（`lp/index.html`）— 自社プロダクトのLP
2. **営業サイト自体**（`services/index.html`）— 「この品質で作ります」の見本
3. **架空店舗のサンプルLP** — 受注ターゲット業種のサンプルを1点、最初の営業前にClaudeに作らせる（30分）

## 6. 税務・手続きの最低限

- 開業届＋青色申告承認申請書を提出（[company-setup-guide.md](./company-setup-guide.md) 参照）。
- 給与所得者の副業なら、所得（売上−経費）20万円/年超で確定申告が必要。月5万ペースなら確実に対象なので、会計ソフトを最初から入れる。
- 直接受注（自サイト経由の前払い）を行う場合は特定商取引法に基づく表記を営業サイトに掲載する。

## 7. 収支シミュレーション（Month 3以降の定常状態）

| 項目 | 金額/月 |
| --- | --- |
| LP制作 2件（うち1件ココナラ手数料後） | +¥53,400 |
| 保守契約 3件 | +¥9,000 |
| 会計ソフト・ドメイン等 | −¥1,500 |
| **手残り目安** | **約¥60,900** |

保守契約が10件を超えた時点（月3万円の固定収入）で、受託を月1件に減らしてWakeUpQR・自社プロダクトに時間を再配分する。

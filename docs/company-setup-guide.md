# 会社設立・開業ガイド（日本・一人アプリ事業向け）

**注意:** 本ガイドは一般的な情報の整理であり、法務・税務の専門アドバイスではありません。実行前に税務署・法務局の公式情報、または税理士・司法書士に必ず確認してください（制度・金額は変わることがあります）。

---

## 0. 結論（推奨ルート）

**いきなり法人を作らず、個人事業主として開業する。**

理由:

- 設立費用¥0・手続きは書類1枚（開業届）。
- アプリ収益が出る前の法人は、住民税均等割（赤字でも年約7万円）や税理士費用だけが出ていく。
- App Storeは個人アカウントで公開可能（開発者名は個人名表示になる点だけ許容する）。
- 法人化は「利益が安定して年500万円超」or「法人名義が営業上必要」になってから遅くない（個人→法人の移行=法人成りは一般的な手順）。

## 1. ステップ1: 個人事業主として開業する

| やること | 提出先 | 期限 | 費用 |
| --- | --- | --- | --- |
| 開業届（個人事業の開業・廃業等届出書） | 所轄の税務署 | 開業から1ヶ月以内 | ¥0 |
| 青色申告承認申請書 | 所轄の税務署 | 開業から2ヶ月以内（同時提出が確実） | ¥0 |

- **両方同時に出すこと。** 青色申告により最大65万円の特別控除（e-Tax申告の場合）と赤字の3年繰越が使える。開発費が先行する初年度はこの繰越が特に効く。
- 提出は e-Tax、または freee開業・マネーフォワード開業（無料）で書類を自動生成して郵送でも可。
- 屋号は開業届に書ける（例:「WakeUpQR開発室」など）。銀行の屋号付き口座も作れる。

### 開業後すぐやること

- 事業用の銀行口座とクレジットカードを分ける（経理が劇的に楽になる）。
- 会計ソフト（freee / マネーフォワード、月1,000円前後）を契約し、口座連携する。
- Apple Developer Program（個人、$99/年）に登録する。
- インボイス（適格請求書発行事業者）は、**アプリストア経由のtoC販売が主なら当面登録不要なことが多い**が、消費税の扱いはストアの契約形態に依存するため、収益が立ち始めたら税理士に確認する。

## 2. ステップ2: 法人化の判断基準

以下のいずれかを満たしたら法人化を検討する:

- 事業利益が**安定して年500〜800万円**を超える（所得税率が法人税率を上回り始める目安）。
- 法人契約・法人名義が必須の取引先が現れた。
- 従業員を雇う、または外部資本を入れたい。

## 3. ステップ3: 法人の形態を選ぶ

| 項目 | 合同会社（LLC） | 株式会社 |
| --- | --- | --- |
| 設立費用（実費） | 約¥60,000〜100,000 | 約¥180,000〜250,000 |
| 定款認証 | 不要 | 必要（公証人手数料） |
| 決算公告義務 | なし | あり |
| 対外信用・資金調達 | やや劣る | 高い（VC調達は実質こちら一択） |
| 向いているケース | 一人アプリ会社・受託なし・調達なし | 採用・調達・大手取引を見据える場合 |

**一人アプリ会社なら合同会社で十分。** 後から株式会社への組織変更も可能。

## 4. ステップ4: 法人設立の手順（合同会社の場合）

1. **基本事項を決める:** 商号（会社名）、本店所在地（自宅可。バーチャルオフィスも可だが銀行審査に注意）、事業目的（「スマートフォンアプリケーションの企画・開発・運営・販売」等）、資本金（1円から可能だが、当面の経費6ヶ月分=50〜100万円程度が現実的）。
2. **定款を作成:** freee会社設立／マネーフォワード会社設立（無料）を使うと書類一式を自動生成できる。電子定款にすると印紙代¥40,000が不要になる。
3. **資本金の払込:** 発起人個人の口座に振り込み、通帳コピーを取る。
4. **法務局で設立登記:** 登録免許税¥60,000（合同会社）。登記完了日が会社設立日。
5. **設立後の届出（期限あり・漏れ注意）:**
   - 税務署: 法人設立届出書、青色申告承認申請書（設立3ヶ月以内）、給与支払事務所等の開設届出書
   - 都道府県税事務所・市区町村: 法人設立届出書
   - 年金事務所: 健康保険・厚生年金の新規適用届（**一人社長でも役員報酬を出すなら社会保険加入は必須**）
6. **法人口座開設:** ネット銀行（GMOあおぞら・住信SBI等）が審査が速い。LP・事業計画書が審査資料として役立つ。

## 5. アプリ事業に固有の法務準備

ストア公開・課金開始までに以下を用意する（LPやアプリ内から必ずリンクする）:

- **プライバシーポリシー:** App Store審査の必須要件。WakeUpQRは「カメラはQR読取のみに使用し、映像・QR内容を外部送信しない」ことを明記すると審査・訴求の両方で有利。
- **利用規約:** アラームの限界（再起動・強制終了・OS設定変更までは防げない）と免責を明記する。README記載の注意書きをベースにできる。
- **特定商取引法に基づく表記:** アプリ内課金のみでApple経由の場合でも、Webサイトで直接販売（Stripe等）を行うなら必須。個人の場合、氏名・住所の扱いは最新の消費者庁ガイドラインを確認すること。

## 3. 修正した不具合

計画工数に「未定」と入力した週（10/19・10/26）で **必要人数が #VALUE!** になっていました。
文字列が入っていても壊れないよう修正し、「未定」の週は必要人数が**空欄**になります。

```
=IF(OR(NOT(ISNUMBER(G14)),キャパシティ!$D$29=0),"",ROUNDUP(G14/キャパシティ!$D$29,0))
```

## 4. 手入力する項目
- **週間スケジュール**：引継ぎ完了企業数・実績工数・実働人数・ステータス・課題・次週アクション
- **ガントチャート**：各タスクの進捗率
- **案件進捗管理**：各社の工数4項目（**ここを入れないと処理可能社数・必要追加人数が算出されません**）・難易度・ステータス・担当・各日付
- **キャパシティ**：人数・週稼働時間・比率・難易度係数・**ママワークス月別採用予定**・計画実運用累計

## 5. 自動計算する項目
実運用完了企業数／必要人数／1社あたり平均工数／合計工数／総必要工数（難易度調整後）／
週・月あたり処理可能工数／月あたり移管可能件数／1人あたり処理可能社数／必要追加人数／
採用計画の稼働人数・処理能力・過不足／KPIカード16枚／件数進捗率・工数進捗率

## 7. 暫定計画値について
計画実運用累計（10月30社／11月50社／12月75社）とママワークスの採用人数（10月2名／11月2名／12月1名）は
すべて**暫定計画値**です。実際の採用計画・実工数が判明した時点で入力値を更新すると、
処理可能社数・必要追加人数・過不足が自動で再計算されます。

### ③ #VALUE! エラーの修正
計画工数に「未定」と入力すると **必要人数が #VALUE!** になっていました。
文字列が入っていても壊れないよう数式を修正し、「未定」の週は必要人数が**空欄**になります。

```
=IF(OR(NOT(ISNUMBER(G14)),キャパシティ!$D$29=0),"",ROUNDUP(G14/キャパシティ!$D$29,0))
```

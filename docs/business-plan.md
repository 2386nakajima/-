# 事業計画書 — WakeUpQR

**作成日:** 2026-07-16
**ステータス:** ドラフト v1（数値・価格はすべて仮説。ローンチ後の実データで更新する）

---

## 1. ビジョン・ミッション

- **ビジョン:** 「起きられない」をテクノロジーで解決し、朝の失敗をゼロにする。
- **ミッション:** 物理的な行動（QRコードのスキャン）と結びついた、絶対に二度寝できない目覚まし体験を提供する。
- **事業形態:** 一人アプリ会社（スモールビジネス）。外部資金調達は行わず、低コスト・高利益率で運営する。

## 2. 解決する課題

- 目覚ましを止めて二度寝してしまう「無意識の解除」は、通常のアラームアプリでは防げない。
- 遅刻・寝坊は学業・仕事・信用に直結する実害があり、ユーザーの支払い意欲が高い課題である。
- 既存の「ミッション型アラーム」（計算問題・シェイクなど）は布団の中で完了できてしまうものが多い。

## 3. ソリューション

**WakeUpQR** — 事前に登録したQRコード（洗面所・玄関・冷蔵庫などに貼る）を実際にスキャンするまで止められない目覚ましアプリ。

- 布団から**物理的に離れる**ことを強制する設計。
- 機能を「QRで起きる」一点に絞り、設定3ステップで使い始められるシンプルさを競合との差別化軸にする。
- カメラ映像・QR内容は端末内で完結し、外部送信しない（プライバシー訴求）。

## 4. 市場

- 世界のアラーム／睡眠系アプリ市場では、ミッション型アラーム「Alarmy（おこしてME）」が長期にわたりヘルスケアカテゴリ上位を維持しており、「強制起床」に金を払うユーザー層の存在は実証済み。
- 本事業はニッチ特化戦略を取る。市場全体のシェアではなく、**「QRスキャン式が最も確実」と考える層**を確実に取りに行く。
- 初期ターゲット: 日本国内の学生・若手社会人（遅刻の実害が大きく、スマホ課金に抵抗が少ない層）。

## 5. 競合分析

| 競合 | 強み | 弱み（＝当社の勝ち筋） |
| --- | --- | --- |
| Alarmy（おこしてME） | 知名度・多機能・ミッション多数 | 多機能ゆえに複雑。サブスク価格が比較的高い |
| iOS標準時計 | 無料・OS統合 | 強制力ゼロ。二度寝を防げない |
| Sleep Meister等の睡眠計測系 | 睡眠分析 | 「起こす強制力」が主目的ではない |

**ポジショニング:** 「QR特化 × 最小の操作 × 低価格買い切り」。機能の多さでは戦わない。

## 6. 収益モデル（概要）

詳細は [monetization-plan.md](./monetization-plan.md) を参照。

- **フリーミアム:** 基本機能（アラーム1件・QR1枚）は無料。Pro（複数アラーム、スヌーズ厳格化、起床統計など）を有料解放。
- **価格仮説:** Pro 買い切り ¥600（サブスク疲れ層への差別化。実データを見て変更可）。
- 広告は初期は入れない（起床という信頼が命の場面でUXを壊さない）。

## 10. リスクと対策

| リスク | 対策 |
| --- | --- |
| iOSの制約でアラームの強制力が不完全（再起動・強制終了で回避可能） | LP・ストア説明に限界を明記し、期待値を管理。AlarmKit等のOS機能を最大限活用 |
| 需要がない | Phase 1の事前登録で開発前に検証。100件未達なら企画を修正 |
| 競合の模倣 | ブランド（「QRで起きる」の第一想起）とレビュー資産を先行して積む |
| 個人開発の停滞 | フェーズごとにゴールを小さく区切る。本ドキュメント群を意思決定の基準にする |

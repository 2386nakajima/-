## 3. 自動計算する項目（**薄いグレーセル**）

| シート | 項目 | ロジック |
|---|---|---|
| 週間スケジュール | 実運用累計企業数 | 明細の実運用開始日が当週末以前の社数を自動集計 |
| 週間スケジュール | 必要人数 | 計画工数 ÷ 1人あたり週有効稼働時間（キャパシティ連動） |
| 週間スケジュール | 1社あたり平均工数 | 実績工数 ÷ 実績対象企業数 |
| 案件進捗管理 | 合計工数 | 給与計算＋資料回収＋顧客対応＋質問対応 |
| キャパシティ | 総必要工数 | Σ(各社工数 × 難易度係数)。**難易度未判定はB係数で暫定計上** |
| キャパシティ | 週/月あたり処理可能工数 | (秘書＋ワーカー)×週有効時間 − 教育工数 − 品質確認工数 |
| キャパシティ | 現在人数で処理可能な企業数 | 月あたり処理可能工数 ÷ 1社あたり平均工数 |
| キャパシティ | **必要追加人数** | (総必要工数 − 月処理可能工数) ÷ 1人あたり月間有効稼働時間 |
| キャパシティ | 移管ペース／残社数／週処理可能社数 | 実績から自動 |
| KPI | 14枚のカード全部 | 明細・キャパシティ・週間スケジュールから自動集計 |
| KPI | 件数進捗率／工数進捗率 | 週ごとに明細の日付を遡って自動算出 |

### 検算例（動作確認済み）
20社に工数7.0h／難易度 A10・B6・C4 を入力した場合:
総必要工数 `10×7×1.0 + 6×7×1.3 + 4×7×1.7 = 172.2h` → 1社平均 8.61h → 現在人員(5名)で **51社** 処理可能 → 追加必要人数 **0名**。
110社全件に入力すると総必要工数 1,001h → 追加必要人数 **6名**と表示されます。

## 5. 10月末時点で確認すべき判断材料

シート5「KPI」とシート4「キャパシティ」で、以下がすべて数値で確認できます。

1. **何社まで実運用できているか** → KPI「実運用累計企業数」
2. **1社あたり何時間かかっているか** → KPI「1社あたり平均工数」／キャパシティ「1社あたり平均工数（難易度調整後）」
3. **現在の人員で何社まで対応可能か** → キャパシティ「現在人数で処理可能な企業数」
4. **追加人員が何名必要か** → キャパシティ「必要追加人数」＋体制判定
5. **今後どの程度の処理能力があるか** → 「週あたり処理可能社数」「現在の移管ペース（社/週）」「残工数」

あわせて、自走可能企業数・完全移管企業数・残企業数も KPI カードで確認できます。

## 6. 進捗管理ルール（3軸評価）

「何社移管したか」だけでは判断しません。

| 軸 | 内容 | 確認場所 |
|---|---|---|
| ① 件数進捗 | 何社が各ステータスまで進んだか | KPI グラフ①・カード |
| ② 工数進捗 | 全体工数のうち何時間分を移管できたか | KPI グラフ⑤・週次データ |
| ③ 自走進捗 | 何社がAn-field様の日常的な確認なしで運用できるか | KPI「自走可能」「完全移管」 |

**完全移管の定義**: 資料回収・給与計算・不明点対応・顧問先とのやり取り・納品・担当者管理まで、
An-field様の日常的な管理なしで完結する状態。「給与計算ができる状態」は完全移管ではありません。

**移管ステータス6段階**: 1.未着手 → 2.引継ぎ中 → 3.初回計算 → 4.検証中 → 5.自走可能 → 6.完全移管

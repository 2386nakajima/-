## 5. 重要な管理ルール（シート内にも記載済み）

### 「引き継ぎ完了」の定義
単に業務説明を受けた状態は「完了」ではありません。以下**すべて**を確認できた案件のみを完了とします。

1. 業務内容理解　2. 勤怠情報取得可能　3. 給与計算可能　4. チェックリスト更新可能
5. 顧客対応方法理解　6. 納品方法理解　7. 進捗管理更新可能　8. 担当者確定

### 判定ルール
- **9/27 時点で100件の引き継ぎが完了していない場合** → 10月1日の完全移行は「**リスクあり**」
- **8/30 時点で3〜4名程度の運用体制が確保できていない場合** → 「**要再計画**」

### スケジュールの考え方
9月末に引き継ぎを開始するのではなく、**9月第4週（〜9/27）までに100案件の引き継ぎを完了**させ、
**9/28〜9/30 は新規引き継ぎを行わず**、修正・確認・リハーサルのバッファ期間として使用します。

## 6. 計画値についての注意

**想定総工数 480時間／1名あたり約120時間／週20〜25時間稼働／4名体制／週間引き継ぎ件数**は、
いずれも現時点の**計画値・試算値**であり、確定実績ではありません。
シート上でも「計画値（試算）」と明記しています。
初期10〜30案件の実績が出た段階で1件あたりの平均工数を再計算し、計画を見直してください。

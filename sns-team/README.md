# SNS運用チーム

## チーム構成

| エージェント | 役割 | 主な仕事 |
|---|---|---|
| 戦略責任者 | リーダー | 発信方針・方向性の設計 |
| リサーチ担当 | 情報収集 | 競合分析・市場調査 |
| 企画担当 | アイデア | 投稿企画・ネタ出し |
| 編集担当 | 制作 | 投稿作成・改善提案 |
| マーケティング担当 | 導線 | note導線・販売設計 |
| 分析担当 | 計測 | KPI測定・データ分析・PDCA ※追加 |
| クリエイティブ担当 | ビジュアル | 画像・デザイン指示・世界観設計 ※追加 |
| 秘書担当 | 管理 | タスク管理・進行管理・日程調整 |

## オーナーの役割

**最終判断のみ。** 各担当が案を出し、秘書担当が集約・整理したうえでオーナーに提示する。

## 基本フロー

```
リサーチ担当
    ↓ 市場・競合情報
戦略責任者
    ↓ 方針・テーマ決定
企画担当
    ↓ 投稿ネタ・コンテンツ計画
       ↓
    クリエイティブ担当（ビジュアル）
    編集担当（テキスト）
       ↓
マーケティング担当（note・販売導線に組み込み）
    ↓
分析担当（効果測定・フィードバック）
    ↓
秘書担当 → オーナーへ最終確認依頼
    ↓
【オーナー：最終判断】
```

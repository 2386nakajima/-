# SMTG 顧客カルテ（Google Apps Script）

Google カレンダーの「【SMTG】」予定を自動取り込みし、企業ごとのカルテ（面談履歴・タスク・関連動画）をスプレッドシートに保存して管理する Web アプリです。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `appsscript.json` | プロジェクト設定（タイムゾーン・OAuth スコープ） |
| `Code.gs` | サーバー側ロジック（カレンダー同期・データ保存） |
| `Index.html` | Web アプリの画面（HTML/CSS/JS 一体） |

## 貼り付け手順

1. [script.google.com](https://script.google.com) を開き、「新しいプロジェクト」を作成する
2. 左上のプロジェクト名をクリックし、任意の名前（例：`SMTG 顧客カルテ`）に変更する
3. **appsscript.json を貼り付ける**
   - 左の歯車アイコン（プロジェクトの設定）を開き、「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェックを入れる
   - エディタに戻り `appsscript.json` を開いて、既存の内容をすべて削除し、本フォルダの `appsscript.json` の内容を貼り付ける
4. **Code.gs を貼り付ける**
   - エディタの `コード.gs`（既定ファイル）を開き、既存の内容をすべて削除して `Code.gs` の内容を貼り付ける
5. **Index.html を作成する**
   - エディタの「＋」→「HTML」を選び、ファイル名を `Index` にする（拡張子 `.html` は自動付与）
   - 既存の内容をすべて削除し、`Index.html` の内容を貼り付ける
   - ※ファイル名は必ず `Index` にしてください（`Code.gs` の `doGet` が `Index` を参照します）
6. 保存（Ctrl/Cmd + S）

## デプロイ手順（Web アプリとして公開）

1. 右上「デプロイ」→「新しいデプロイ」
2. 種類の選択（歯車アイコン）→「ウェブアプリ」
3. 設定：
   - 次のユーザーとして実行：**ウェブアプリケーションにアクセスしているユーザー**
   - アクセスできるユーザー：利用範囲に合わせて選択（例：自分のみ／組織内）
4. 「デプロイ」を押し、初回は権限の承認（カレンダー読み取り・スプレッドシート・Drive・メールアドレス）を許可する
5. 発行された URL にアクセスすると画面が表示されます

## 使い方のポイント

- **データ保存先**: 初回アクセス時にユーザーごとのスプレッドシート「SMTG 顧客カルテ データ」が自動作成されます（画面右上「保存データを開く」から確認可能）
- **カレンダー同期**: 「↻ カレンダー同期」で、過去90日〜未来180日の予定のうちタイトルが `【SMTG】支援ユニット名：会社名` 形式のものを取り込みます
  - 例：`【SMTG】採用支援＋営業支援：株式会社ABC 様` → 企業「株式会社ABC」に「採用支援」「営業支援」の2ユニットを紐付け
  - 辞退（不参加）にした予定はスキップされます
  - 予定の説明欄にある YouTube / Vimeo / Loom / Google Drive の動画 URL は「関連動画」として自動登録されます
- **企業統合**: 表記ゆれで重複した企業は、詳細画面の「統合」から予定・タスク・動画ごと1社にまとめられます

## 動作確認（任意）

エディタで関数 `runParserTests` を選んで実行すると、予定タイトルの解析ロジックのテストが走ります。`Parser tests passed: 3` と表示されれば正常です。

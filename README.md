# QuizBank — 文字起こしから1問1答の問題集を作るサイト

講義・会議・動画などの文字起こしを貼り付けると、生成AIが1問1答の問題を10問以上まとめて作り、
そのまま自分専用の問題集（マスターデータ）として蓄積・演習できる個人用Webアプリです。

**運用コストは0円**にできます（AIは無料枠、公開は無料の静的ホスティング、保存はブラウザ内）。

Expo Router（React Native for Web）製で、`npm run web` でブラウザから使えます。

## できること

| 画面   | 内容                                                                                                                |
| ------ | ------------------------------------------------------------------------------------------------------------------- |
| 作成   | 文字起こしを貼り付けて問題を生成。1問ずつ内容を直してから保存できる                                                 |
| 問題集 | 蓄積した問題のマスターデータ管理（検索・タグ/出典で絞り込み・編集・削除・手動追加・JSON/CSV書き出し・JSON取り込み） |
| 演習   | 範囲を選んで1問1答を出題。○×を記録し、「苦手・未解答のみ」で復習できる                                              |
| 設定   | 使うAI・APIキー・モデルID・1回あたりの問題数・全データ削除                                                          |

## 無料で使うための構成

| 要素       | 無料の選択肢                         | 補足                                                                                                                            |
| ---------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| 生成AI     | **Google Gemini の無料枠**（推奨）   | [AI Studio](https://aistudio.google.com/app/apikey) でキーを無料発行。既定モデルは `gemini-2.5-flash`                           |
| 生成AI     | **OpenRouter の `:free` モデル**     | [キー発行](https://openrouter.ai/keys)。モデルIDの末尾が `:free` のものは無料。提供状況が変わるためモデルIDは設定画面で変更可能 |
| 生成AI     | **オフライン生成**（キー不要）       | 後述のルールベース生成。完全にローカルで動くので上限も課金もなし                                                                |
| サーバー   | 不要                                 | バックエンドなし。ブラウザから直接AIサービスを呼ぶ                                                                              |
| データ保存 | ブラウザのlocalStorage               | DBもログインも不要                                                                                                              |
| 公開       | GitHub Pages / Cloudflare Pages など | 静的サイトとして書き出すだけ。本リポジトリにGitHub Pages用のワークフローを同梱                                                  |

有料の **Anthropic Claude** も選べます（品質を最優先したい場合のみ）。設定画面でいつでも切り替えられます。

> 無料枠にはレート制限があります。`429` が出たら少し待つか、設定で1回の問題数を減らしてください。
> 長い文字起こしは自動で分割して複数回呼び出します。

## 生成方法は2種類

1. **AI生成（推奨）** — 選んだAIサービスに文字起こしを送り、その内容だけを根拠に
   定義・数値・理由・手順などが偏らないよう1問1答を作ります。
2. **オフライン生成** — APIキーなしで動くルールベース生成。日本語の頻出パターン
   （「XとはY」「AはB」「〜のは〜ためです」「数値」「重要語の穴埋め」）から問題を組み立て、
   フィラー（えー、あのー等）は自動で除去します。

## 使い方

```bash
npm install       # 初回のみ
npm run web       # ブラウザで開く（http://localhost:8081）
```

1. 「設定」タブで使うAI（既定はGemini）を選び、無料APIキーを貼り付けて保存
2. 「作成」タブに文字起こしを貼り付け、生成ボタンを押す
3. 生成結果を確認・修正して「保存する」
4. 「演習」タブで復習、「問題集」タブで管理

## 無料で公開する

### GitHub Pages（ワークフロー同梱）

1. リポジトリの **Settings → Pages → Source** を `GitHub Actions` にする
2. `main` ブランチに push（または Actions から手動実行）すると
   `.github/workflows/deploy-pages.yml` がビルドして公開します
3. 公開URLは `https://<ユーザー名>.github.io/<リポジトリ名>/`

サブパス配信のため、ワークフローは `EXPO_BASE_URL=/<リポジトリ名>` を付けてビルドします。

### そのほか（Cloudflare Pages / Netlify など）

```bash
npx expo export -p web   # dist/ に静的サイトを出力
```

`dist/` をそのままアップロードすれば動きます（ルート配信ならbaseUrlの指定は不要）。

## データの扱い（個人利用前提）

- 問題・文字起こし・APIキーはすべて**ブラウザのlocalStorage**にのみ保存されます。サーバーもログインもありません。
- APIキーはブラウザから各AIサービスへ直接送信されます。共有PCでは使わないでください。
  （公開サイトに置く場合も、キーを入力するのは自分のブラウザだけなので他人には渡りません）
- バックアップは「問題集」タブの **JSON書き出し**、復元は **JSON取り込み** で行えます。
  ブラウザのサイトデータを消すと問題も消えるため、定期的な書き出しを推奨します。

## 構成

```
src/
  app/            画面（expo-router）
    index.tsx     作成
    bank.tsx      問題集（マスターデータ管理）
    study.tsx     演習
    settings.tsx  設定
  components/ui.tsx  共通UI（ナビ・カード・ボタン・入力）
  lib/
    types.ts      ドメイン型・AIサービス定義
    storage.ts    localStorageストア（CRUD・入出力）
    generator.ts  ルールベース生成（オフライン）
    ai.ts         生成AI呼び出し（Gemini / OpenRouter / Claude）
app.config.js     EXPO_BASE_URL でサブパス配信に対応
.github/workflows/deploy-pages.yml  GitHub Pagesへの無料デプロイ
```

## 備考

- スマホアプリ（iOS/Android）としても起動できますが、保存はWeb（localStorage）前提のため、
  ネイティブでは保存が行われません。Webブラウザでの利用を想定しています。

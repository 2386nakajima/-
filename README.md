# QuizBank — 文字起こしから1問1答の問題集を作るサイト

講義・会議・動画などの文字起こしを貼り付けると、1問1答の問題を10問以上まとめて生成し、
そのまま自分専用の問題集（マスターデータ）として蓄積・演習できる個人用Webアプリです。

Expo Router（React Native for Web）製で、`npm run web` でブラウザから使えます。

## できること

| 画面   | 内容                                                                                                                |
| ------ | ------------------------------------------------------------------------------------------------------------------- |
| 作成   | 文字起こしを貼り付けて問題を生成。1問ずつ内容を直してから保存できる                                                 |
| 問題集 | 蓄積した問題のマスターデータ管理（検索・タグ/出典で絞り込み・編集・削除・手動追加・JSON/CSV書き出し・JSON取り込み） |
| 演習   | 範囲を選んで1問1答を出題。○×を記録し、「苦手・未解答のみ」で復習できる                                              |
| 設定   | APIキー・生成モデル・1回あたりの問題数・全データ削除                                                                |

## 生成方法は2種類

1. **AI生成（推奨）** — Anthropic の Claude API（Messages API）をブラウザから直接呼び出し、
   文字起こしの内容だけを根拠に定義・数値・理由・手順などバランスよく出題を作ります。
   長文は自動で分割して章ごとに生成します。**利用にはAPIキーが必要です。**
2. **オフライン生成** — APIキーなしでも動くルールベース生成。日本語の頻出パターン
   （「XとはY」「AはB」「〜のは〜ためです」「数値」「重要語の穴埋め」）から問題を組み立てます。
   フィラー（えー、あのー等）は自動で除去します。

## 使い方

```bash
npm install       # 初回のみ
npm run web       # ブラウザで開く（http://localhost:8081）
```

1. 「設定」タブで Anthropic の APIキー（`sk-ant-...`）を入力して保存（AI生成を使う場合のみ）
2. 「作成」タブに文字起こしを貼り付け、生成ボタンを押す
3. 生成結果を確認・修正して「保存する」
4. 「演習」タブで復習、「問題集」タブで管理

静的サイトとして書き出す場合は `npx expo export -p web`（`dist/` に出力）。
そのまま任意の静的ホスティングに置けます。

## データの扱い（個人利用前提）

- 問題・文字起こし・APIキーはすべて**ブラウザのlocalStorage**にのみ保存されます。サーバーもログインもありません。
- APIキーはブラウザから直接 `api.anthropic.com` に送られます（`anthropic-dangerous-direct-browser-access` ヘッダーを使用）。
  共有PCや公開ホスティングでは使用しないでください。
- バックアップは「問題集」タブの **JSON書き出し**、復元は **JSON取り込み** で行えます。
  ブラウザのサイトデータを消すと問題も消えるため、定期的な書き出しを推奨します。

## 構成

```
src/
  app/            画面（expo-router）
    index.tsx     作成
    bank.tsx      問題集（マスターデータ管理）
    study.tsx     演習
    settings.tsx  設定
  components/ui.tsx  共通UI（ナビ・カード・ボタン・入力）
  lib/
    types.ts      ドメイン型
    storage.ts    localStorageストア（CRUD・入出力）
    generator.ts  ルールベース生成（オフライン）
    anthropic.ts  Claude API 呼び出し
```

## 備考

- スマホアプリ（iOS/Android）としても起動できますが、保存はWeb（localStorage）前提のため、
  ネイティブでは保存が行われません。Webブラウザでの利用を想定しています。
